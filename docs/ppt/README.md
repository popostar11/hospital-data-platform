# 项目介绍 PPT（HTML 演示）

> 用大白话介绍 **医院数据管理平台 · 急救绿道** 是什么、怎么做的、怎么用。
> 13 页，纯静态 HTML，双击即可讲。

---

## 怎么打开

**双击 `index.html`** 即可（不需要装任何东西、不需要联网、不需要后端）。

建议按 `F` 全屏，然后用方向键翻页 —— 和 PowerPoint 的放映体验一致。

| 按键 | 作用 |
|---|---|
| `←` `→` / 空格 | 上一页 / 下一页 |
| `F` | 全屏（放映用） |
| `O` | 缩略图概览（快速跳页） |
| `S` | 演示者视图（当前页 + 下一页 + 计时） |
| `T` | 循环切换主题（共 36 套，已内置 6 套常用） |
| `N` | 备注抽屉（每页都写了讲稿提示） |
| 手机/平板 | 左右滑动翻页 |

> 每页的 `N` 备注里都写了**这一页该怎么讲**，不是念稿，是提示信号。

| 07 | **数据怎么流** | 五步流程 + **四类刷新机制图例** |

- 第 7 页：流程下方说明"蓝边 = 服务端在做的事"以及三种刷新机制
- 第 8 页：架构图下方说明"蓝边 = 核心层 / 无蓝边 = 配套 / 单向依赖"

## 目录结构

```
docs/ppt/
├── index.html          ← 演示文稿本体（双击这个）
├── assets/             ← 样式与运行时（来自 html-ppt skill）
│   ├── base.css        设计令牌与基础版式
│   ├── runtime.js      键盘导航 / 演示者视图 / 主题切换
│   ├── themes/         36 套主题（当前用 corporate-clean）
│   └── animations/     入场动效
├── images/             ← 用到的截图（均为脱敏后的实机渲染）
│   ├── screen.png      大屏终端
│   ├── admin.png       后台工作台
│   └── pages.png       公网静态版
└── preview/            ← 13 页导出的 PNG（1600×900）
```

`preview/*.png` 可以直接拖进 PowerPoint / WPS 当素材用；
如果想直接得到 `.pptx` 文件，把这 13 张图按页插入即可。

## 关于素材与隐私

- 三张截图都是**用脱敏演示数据渲染出来的实机截图**，不是设计稿；
- 画面里的机构名称是占位名 `示例市第二人民医院`，患者姓名为脱敏形式（如 `王*涛`）；
- 仓库中不包含现场实拍素材与任何真实机构名称；
- 全部数据为**合成的示例数据**，不代表任何真实机构或真实统计结果。
