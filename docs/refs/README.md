# `docs/refs/` 目录说明

本目录存放**界面渲染截图**，仅用于文档展示与版面比对：

| 文件 | 内容 |
|---|---|
| `screen-shot.png` | 大屏终端 1920×1080 实机渲染截图 |
| `admin-dashboard.png` | 管理后台工作台截图 |
| `admin-login.png` | 管理后台登录页截图 |

## 关于源素材

本项目初期依据医院现场采集的素材（大屏正面照片、侧向照片、大屏录像）还原版面与交互。这些源素材**因隐私与合规原因不随仓库发布**，也不参与任何构建或测试流程。

因此：

- 本目录**只保留界面渲染截图**，不含任何现场照片/录像及其派生文件；
- 截图中的机构名称、患者姓名与全部统计数值均为**合成演示数据**，不代表任何真实机构的统计值；
- 版面与交互 1:1 还原参考大屏，数据为合成示例数据。

如需在本地开展版面比对，请自行准备已获授权的素材，并放在仓库外（`tu/` 已在 `.gitignore` 中排除，不会入库）。
